# Educational attainment and health outcomes in New York State

This project demonstrates the relationship between educational attainment and healthcare outcomes in six New York counties. I got my primary data from BWDC and branched out to other data sources after collecting my findings there. I used Svelte and Highcharts for code and data visualization, and I used MapChart and Canva to make the images (maps with arrows and data). :)
